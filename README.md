# 国际会议同声传译和发言队列控制

源提示词摘要：主持人维护代表发言队列、剩余时间、议题和临时插话；翻译团队维护多语种频道、术语和译员交接；字幕人员修正实时文本。队列调整保留版本，发言者切换后旧译文不会误绑定，并提供低延迟大屏模式和多会议厅隔离。

## 技术栈

Qwik City、TypeScript、Qwik UI、Qwik stores、TanStack Query、Modular Forms、Zod、qwik-speak。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62029`

## 可用流程

- 多会议厅独立维护代表、议题和发言队列，切换厅时数据互不影响（绑定、草稿、交接均按厅隔离）。
- 发言人从排队、发言中、完成到跳过，支持临时插话和剩余时间调整；发言开始时厅内活跃频道与该发言建立接续绑定并记录署名人。
- 多语种频道维护译员、术语和交接：启动交接即冻结当前字幕段并作废旧草稿，状态进入待确认；确认后新译员从下一段开始署名。
- 交接状态机为「冻结 → 待确认 → 已确认 / 失败」；失败可从待确认步骤重试，重试只增加尝试次数，不重复归属、不覆盖已发布字幕。
- 字幕按「段 + 版本」组织：同段修正只追加版本且保留逐版本署名，冻结段不可再改，交接后自动开启新段。
- 草稿带属主译员与 epoch 校验；交接发生后旧草稿提交会被拦截丢弃，不会以新译员名义发出。
- 时间线按全局序号展示发言、绑定、交接与字幕版本的先后关系，可按厅过滤。
- 低延迟模式只保留关键状态并停用非必要动态；数据保存在浏览器 localStorage（v2 结构），刷新后继续保留。
